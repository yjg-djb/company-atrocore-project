# MyCompany module

Put project-specific AtroCore customizations here.

Typical additions:

- entities, services, repositories, controllers and jobs under `app/`
- metadata, layouts and language files under `app/Resources/`
- database migrations under `app/Migrations/`
- frontend customizations under `client/`

Do not edit `vendor/atrocore/*` for business customization. If core behavior must change, fork the affected package and point Composer to the fork.
